# Кошки-мышки

Консольная лабораторная работа на C# (.NET 8).

## Запуск

Из папки `laba02`:

```sh
dotnet run
```

Программа предлагает выбрать тест от 1 до 4. Номер можно передать аргументом:

```sh
dotnet run -- 1
dotnet run -- 2
dotnet run -- 3
dotnet run -- 4
```

В текущем рабочем каталоге читается `N.ChaseData.txt`, результат записывается в `N.PursuitLog.txt`. Отчёт и сообщение об успешном сохранении в консоль не выводятся. На экране остаются приглашение к выбору теста и сообщения об ошибках.

Входные файлы находятся в папке проекта и копируются в каталог сборки. Результаты сборки (`bin`, `obj`) и настройки Visual Studio исключены из Git. Четвёртый тест проверяет ситуацию, когда кот не вступил в игру.

## Классы

- `Player` хранит имя, позицию, состояние и пройденное расстояние; выполняет движение по круговому полю.
- `Game` управляет игроками, проверяет поимку и формирует строки отчёта.
- `GameFileProcessor` выполняет все операции с файлами: читает команды построчно, запускает их обработку и сохраняет результат. При ошибке возвращает `false` и описание в `ErrorMessage`.
- `Program` выбирает номер теста, запускает обработчик и сообщает об ошибках.

## Правила

Размер поля — от 1 до 10000 клеток. Первая команда `M` или `C` задаёт начальную позицию и не увеличивает путь. Последующие команды перемещают игрока вперёд или назад с переходом через границы. Расстояние между игроками — модуль разности номеров клеток.

При совпадении позиций после команды мышь считается пойманной, дальнейшее чтение прекращается. Кот получает состояние `Winner`, мышь — `Loser`. Если команды закончились без поимки, участвующая мышь получает `Winner`, участвующий кот — `Loser`. Игрок без начальной позиции сохраняет `NotInGame`; итоговый отчёт формируется и в этом случае.

Неизвестные позиции и расстояние обозначены `??` по тексту задания. В исходных примерах неизвестное расстояние оставлено пустым. Итоговые колонки выровнены, для суммы пройденного пути используется `long`.
